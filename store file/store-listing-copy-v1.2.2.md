### Full Description

# Proxy Toggle: Simple System Proxy Switcher

Proxy Toggle helps you switch Chrome between your operating system proxy and a direct connection with a clean, focused popup.

The toolbar popup remains the place for details: check the current proxy state, toggle manually, and review domains that failed to load. For faster workflows, you can now assign your own keyboard shortcut from Chrome's extension shortcut settings and switch the proxy directly without opening the popup.

## Key Features

- Switch between system proxy and direct connection from the popup
- Optional keyboard shortcut for direct proxy switching
- Optional shortcut notifications with runtime permission
- Clear icon and title feedback for the current proxy state
- Remembers your proxy state across browser sessions
- Collect, copy, and clear domains from failed resources
- Light and dark mode support

## How to Use

1. Click the Proxy Toggle icon to open the popup.
2. Use the switch to enable System Proxy or Direct Connection.
3. Click Set Shortcut to open Chrome's shortcut settings and assign a direct toggle shortcut.
4. Enable shortcut notifications if you want a system notification after shortcut toggles.
5. Review, copy, or clear failed domains from the popup when troubleshooting proxy issues.

## Notes

Shortcut notifications use Chrome's optional notification permission. They are only enabled after you choose to grant the permission. On macOS and some desktop systems, whether notifications appear as banners depends on your system notification settings for Chrome.

# Proxy Toggle：简洁的系统代理切换工具

Proxy Toggle 可以帮助你在 Chrome 中快速切换“使用系统代理”和“直接连接”。界面简洁，适合开发、调试、网络排查，以及经常需要切换代理环境的用户。

工具栏弹窗仍然用于查看详情：你可以确认当前代理状态、手动切换代理，并查看加载失败的域名。新版增加了快捷键入口，你可以在 Chrome 的扩展快捷键设置中自行绑定快捷键，之后无需打开弹窗即可直接切换代理。

## 主要功能

- 在弹窗中切换系统代理和直接连接
- 可选快捷键，直接切换代理状态
- 可选快捷键通知，运行时由用户主动授权
- 图标和标题清晰显示当前代理状态
- 自动记住上次代理状态
- 收集、复制、清空加载失败的域名
- 支持浅色和深色模式

## 使用方式

1. 点击 Proxy Toggle 图标打开弹窗。
2. 使用开关启用 System Proxy 或 Direct Connection。
3. 点击 Set Shortcut，打开 Chrome 扩展快捷键设置并自行绑定快捷键。
4. 如需快捷键切换后的系统通知，可在弹窗中开启 Shortcut Notifications。
5. 代理排查时，可在弹窗中查看、复制或清空失败域名列表。

## 说明

快捷键通知使用 Chrome 的可选通知权限，只有在你主动授权后才会启用。macOS 及部分桌面系统是否弹出横幅，取决于系统中 Chrome 的通知样式设置。
